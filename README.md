# 🍽️ Buscador de Receitas

Aplicação web desenvolvida com **Next.js (App Router)** que permite buscar, visualizar e explorar receitas utilizando a API pública **TheMealDB**.

O projeto foi desenvolvido com foco em organização de layout, boas práticas com Server Components e estilização moderna utilizando CSS Modules e CSS global estruturado.

---

## 🚀 Tecnologias Utilizadas

- **Next.js 15+ (App Router)**
- **React**
- **TypeScript**
- **CSS Modules**
- **CSS Global estruturado**
- **TheMealDB API**
- **Git & GitHub**

---

## 📸 Funcionalidades

- 🔎 Buscar receitas por nome
- 📖 Visualizar detalhes completos da receita
- 🖼 Exibição de imagem otimizada com `next/image`
- 🥘 Listagem automática de ingredientes e medidas
- 📋 Instruções formatadas com quebra de linha
- 🎨 Layout moderno com organização em colunas
- 📱 Responsivo (mobile friendly)
- 🧱 Estrutura com Header e Footer global
- 🧩 Separação clara entre layout, páginas e estilos
